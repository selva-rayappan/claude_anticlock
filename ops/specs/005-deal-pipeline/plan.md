# Implementation Plan: Deal & Pipeline Management

**Branch**: `005-deal-pipeline` | **Date**: 2026-06-15 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/005-deal-pipeline/spec.md`

## Summary

Implement deal and pipeline management for OpsNext: Tenant Admin configures named pipelines
with ordered stages (including Closed Won/Lost stage types), Sales Reps create and manage
deal records (name, value, close date, owner, probability, contact/company associations),
a Kanban board provides visual drag-and-drop stage progression, every transition is written
to an immutable stage history, weighted pipeline value (value × probability) is calculated
per stage, Sales Managers set monthly/quarterly revenue targets and track progress, and
Tenant Admins define custom deal fields. Deal clone (P3) rounds out the feature.

## Technical Context

**Language/Version**: Java 21 (backend) · TypeScript / Node 20 (frontend)

**Primary Dependencies**: Spring Boot 3.4.1 · Spring Data JPA / JJWT 0.12.6 (backend);
Next.js 15 App Router · React 19 · shadcn/ui · TanStack Query · react-hook-form · Zod ·
`@dnd-kit/core` + `@dnd-kit/sortable` (drag-and-drop Kanban board, frontend)

**Storage**: PostgreSQL 16 (schema-per-tenant via TenantJdbcTemplate) · Redis 7 (pipeline
summary weighted-value cache; stage history event cache for real-time board updates)

**Testing**: JUnit 5 + Spring Boot Test (backend) · Vitest + Testing Library (frontend)

**Target Platform**: Linux container (backend API) · Browser / Next.js SSR (frontend)

**Project Type**: Multi-tenant SaaS web application (monorepo: `apps/api` + `apps/web`)

**Performance Goals**: Kanban board loads ≤ 2 s p95 for 500 active deals; deal CRUD ≤
300 ms p95; weighted value recalculation ≤ 3 s p95 after value/probability change;
stage transition records ≤ 100 ms p95

**Constraints**: Stage history MUST be immutable (insert-only, no updates/deletes);
deal soft-delete only (no hard delete by Rep/Manager); cross-pipeline deal movement deferred;
single currency per tenant (Phase 1); `@dnd-kit` chosen over `react-beautiful-dnd` (actively
maintained, accessible); JSONB used for custom field values to avoid wide nullable column tables

**Scale/Scope**: Up to 500 active deals per pipeline displayed on Kanban board; up to 20
pipeline stages; up to 50 custom field definitions per tenant

## Constitution Check

## Database Migrations

All tables in `tenant_{slug}` schema via Flyway tenant migration scripts:

```sql
-- V005.1__pipeline.sql
CREATE TABLE pipeline (
    id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id   UUID NOT NULL,
    name        VARCHAR(150) NOT NULL,
    description TEXT,
    is_default  BOOLEAN NOT NULL DEFAULT FALSE,
    is_active   BOOLEAN NOT NULL DEFAULT TRUE,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE UNIQUE INDEX idx_pipeline_default ON pipeline(tenant_id) WHERE is_default = TRUE;

-- V005.2__pipeline_stage.sql
CREATE TYPE stage_type AS ENUM ('OPEN', 'CLOSED_WON', 'CLOSED_LOST');
CREATE TABLE pipeline_stage (
    id                  UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    pipeline_id         UUID NOT NULL REFERENCES pipeline(id) ON DELETE RESTRICT,
    tenant_id           UUID NOT NULL,
    name                VARCHAR(100) NOT NULL,
    display_order       SMALLINT NOT NULL,
    default_probability SMALLINT NOT NULL DEFAULT 50 CHECK (default_probability BETWEEN 0 AND 100),
    stage_type          stage_type NOT NULL DEFAULT 'OPEN',
    UNIQUE (pipeline_id, display_order)
);

-- V005.3__deal.sql
CREATE TYPE deal_status AS ENUM ('OPEN', 'WON', 'LOST');
CREATE TABLE deal (
    id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id    UUID NOT NULL,
    pipeline_id  UUID NOT NULL REFERENCES pipeline(id),
    stage_id     UUID NOT NULL REFERENCES pipeline_stage(id),
    name         VARCHAR(255) NOT NULL,
    value        NUMERIC(18,2) NOT NULL,
    currency     CHAR(3) NOT NULL DEFAULT 'GBP',
    close_date   DATE NOT NULL,
    owner_id     UUID NOT NULL REFERENCES users(id),
    probability  SMALLINT NOT NULL DEFAULT 50 CHECK (probability BETWEEN 0 AND 100),
    status       deal_status NOT NULL DEFAULT 'OPEN',
    contact_id   UUID REFERENCES contacts(id),
    company_id   UUID REFERENCES companies(id),
    loss_reason  TEXT,
    custom_fields JSONB NOT NULL DEFAULT '{}',
    archived_at  TIMESTAMPTZ,
    created_at   TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at   TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_deal_pipeline_stage ON deal(pipeline_id, stage_id) WHERE archived_at IS NULL;
CREATE INDEX idx_deal_owner ON deal(tenant_id, owner_id) WHERE archived_at IS NULL;

-- V005.4__deal_stage_history.sql
CREATE TABLE deal_stage_history (
    id               UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    deal_id          UUID NOT NULL REFERENCES deal(id),
    tenant_id        UUID NOT NULL,
    from_stage_id    UUID REFERENCES pipeline_stage(id),   -- NULL on deal creation
    to_stage_id      UUID NOT NULL REFERENCES pipeline_stage(id),
    changed_at       TIMESTAMPTZ NOT NULL DEFAULT now(),
    changed_by_id    UUID NOT NULL REFERENCES users(id)
);
CREATE INDEX idx_deal_stage_history_deal ON deal_stage_history(deal_id, changed_at);

-- V005.5__revenue_target.sql
CREATE TYPE period_type AS ENUM ('MONTHLY', 'QUARTERLY');
CREATE TABLE revenue_target (
    id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id    UUID NOT NULL,
    pipeline_id  UUID NOT NULL REFERENCES pipeline(id),
    period_type  period_type NOT NULL,
    target_value NUMERIC(18,2) NOT NULL,
    currency     CHAR(3) NOT NULL DEFAULT 'GBP',
    start_date   DATE NOT NULL,
    UNIQUE (pipeline_id, period_type, start_date)
);

-- V005.6__deal_custom_field_definition.sql
CREATE TYPE field_type AS ENUM ('TEXT','NUMBER','DATE','DROPDOWN','MULTI_SELECT','BOOLEAN');
CREATE TABLE deal_custom_field_definition (
    id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id     UUID NOT NULL,
    name          VARCHAR(100) NOT NULL,
    field_type    field_type NOT NULL,
    options       JSONB,           -- array of strings for DROPDOWN/MULTI_SELECT
    is_required   BOOLEAN NOT NULL DEFAULT FALSE,
    display_order SMALLINT NOT NULL DEFAULT 0,
    is_active     BOOLEAN NOT NULL DEFAULT TRUE,
    UNIQUE (tenant_id, name)
);
```

## API Endpoints Summary

| Method | Path | Roles | Description |
|--------|------|-------|-------------|
| GET | `/api/v1/pipelines` | All | List active pipelines + stages |
| POST | `/api/v1/pipelines` | Admin | Create pipeline |
| PUT | `/api/v1/pipelines/{id}` | Admin | Update pipeline name/description |
| GET | `/api/v1/pipelines/{id}/stages` | All | List stages for pipeline |
| POST | `/api/v1/pipelines/{id}/stages` | Admin | Add stage |
| PUT | `/api/v1/pipelines/{id}/stages/{stageId}` | Admin | Rename / update stage |
| PUT | `/api/v1/pipelines/{id}/stages/reorder` | Admin | Reorder stages (array of ordered IDs) |
| DELETE | `/api/v1/pipelines/{id}/stages/{stageId}` | Admin | Delete stage (guarded) |
| GET | `/api/v1/pipelines/{id}/revenue-targets` | Manager/Admin | List revenue targets |
| POST | `/api/v1/pipelines/{id}/revenue-targets` | Manager/Admin | Set/upsert revenue target |
| GET | `/api/v1/deals` | All | List deals (filterable, paginated) |
| POST | `/api/v1/deals` | Rep/Manager/Admin | Create deal |
| GET | `/api/v1/deals/{id}` | All | Deal detail |
| PUT | `/api/v1/deals/{id}` | Rep (own) / Manager / Admin | Update deal |
| PUT | `/api/v1/deals/{id}/stage` | Rep (own) / Manager / Admin | Move stage |
| PUT | `/api/v1/deals/{id}/close` | Rep (own) / Manager / Admin | Mark Won or Lost |
| DELETE | `/api/v1/deals/{id}` | Manager/Admin (archive) | Archive deal |
| GET | `/api/v1/deals/{id}/stage-history` | All | Stage transition history |
| POST | `/api/v1/deals/{id}/clone` | Rep/Manager/Admin | Clone deal (P3) |
| GET | `/api/v1/deals/kanban` | All | Board payload: deals grouped by stage |
| GET | `/api/v1/deal-custom-fields` | All | List custom field definitions |
| POST | `/api/v1/deal-custom-fields` | Admin | Create custom field definition |
| PUT | `/api/v1/deal-custom-fields/{id}` | Admin | Update definition |
| DELETE | `/api/v1/deal-custom-fields/{id}` | Admin | Deactivate (soft-delete) custom field |

All responses use `{ data, meta, errors }` envelope per Constitution Principle II.
